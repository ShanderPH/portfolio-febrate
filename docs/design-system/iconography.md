# Iconografia

Somente SVG funcional de traço (setas, menu, tema) e marca tipográfica própria nos protótipos. Ícones decorativos usam `aria-hidden`; o controle ou link possui nome acessível. Nenhum emoji, glifo usado como ícone, número técnico falso ou dependência de ícones nova.

Next Icons não foi adicionado: os poucos ícones necessários são SVG nativo e não justificam outra dependência. Avaliar licença, API e necessidade real antes de qualquer adoção. A nuvem histórica de tecnologias foi recuperada como camada opcional, com o mesmo roster, fallback textual e controle de teclado.
